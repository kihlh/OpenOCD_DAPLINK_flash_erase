# STM32 DAP Link OpenOCD 自动烧录GUI工具



## 项目简介

在淘宝上面花了5个大洋买的 DAP Link，太难用了，每次输入都需要使用Keil，而Keil 又太复杂了，不适合我这种业余选手，于是我写了个这个自动烧录工具，适配的 CMSIS-DAP (DAPLink) 调试器，专为 STM32 系列 Cortex-M 内核单片机设计，当然dap支持啥他就支持啥没有中间商赚差价

#### 功能解析：

- 💫  **自动烧录** 可以自动检查编译完成的hex并自动刷入
- 💫  ~~**支持`.bin**`~~  但是我懒得写，要挨个去测试存储地址，先留个坑有空了填
- 💫  支持自定义 SWD **下载速率**：1kHz ~ 10MHz 多档位可选
- 💫  **一键重启**    **一键输入**    **一键进BOOT**
- 💫  **良好的交互**，嗯对，我太懒了，所以一切交互都是按照我的想法做的，所以懒人有福了，不管是拖入还是打开还是编辑都很轻松，包含界面配置保持，和自动查找OpenOCD位置（深度法和系统变量探索法）
- 💫  也支持静默命令行模式 低级模式也是要有的 万一我的用户想再写个自动化呢

##### 一、部署 OpenOCD

这个是必须要有的，因为太大了不可能塞进这个程序，因为我很讨厌让火车拉着自行车跑，所以软件是纯C++实现的，原生实现，我也给你考虑了很多方案，反正任选其一就可以了

- **下载OpenOCD 源文件然后放到本软件目录下解压就行了**，至于重命名啥的也不需要，自动深度探测的（5个目录层级内），就像这样
